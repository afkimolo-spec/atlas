# Atlas Pre-Code Execution Rule

Before writing or modifying any code:

## Read Current Context

Review:

- .ai/context.md
- .ai/current_state.md
- .ai/architecture.md
- .ai/decisions.md
- .ai/tasks.md
- .ai/handover.md

## Understand Before Changing

Confirm:

- The purpose of the change
- Existing implementation
- Dependencies affected
- Potential risks

Do not make architectural changes without documenting the impact.

---

# After Completing Work

Update:

- .ai/current_state.md
- .ai/tasks.md
- .ai/handover.md

Include:

- What changed
- Why it changed
- Any limitations
- Next recommended actions

---

# Architectural Changes

If a change affects:

- System design
- Infrastructure
- Data flow
- Technology choices

Update:

- .ai/architecture.md
- .ai/decisions.md
