# Feature Development Workflow

## Step 1 — Understand

Review:

- Current state
- Architecture
- Existing implementation

## Step 2 — Design

Define:

- Proposed solution
- Components affected
- Risks

## Step 3 — Implement

Developer agent:

- Writes code
- Adds tests
- Updates documentation

## Step 4 — Review

Reviewer agent checks:

- Correctness
- Security
- Maintainability

## Step 5 — Record

Update:

- decisions.md
- current_state.md
- handover.md
