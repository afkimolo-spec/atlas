# Atlas AI Engineering Workspace

## Purpose

Atlas is a local AI-assisted engineering environment designed for autonomous software development, research, automation, and infrastructure management.

## Structure

- `.ai` - AI context, memory, decisions, and workflows
- `docs` - Human-readable documentation
- `infra` - Infrastructure definitions
- `scripts` - Automation scripts
- `logs` - Operational logs
- `temp` - Temporary workspace

## Current Status

Foundation phase completed.

## AI Environment

Models are hosted externally and accessed through local inference services.
